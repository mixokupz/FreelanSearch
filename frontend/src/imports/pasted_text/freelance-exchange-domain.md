Информационная система «Биржа фрилансеров»

Платформа предназначена для взаимодействия между фрилансерами (исполнителями), предлагающими свои услуги, и заказчиками (клиентами), которые ищут специалистов для выполнения работ. Система обеспечивает полный цикл сотрудничества: от поиска исполнителя до завершения проекта и взаиморасчетов.

Описание предметной области

Все пользователи платформы делятся на две основные категории: Фрилансеры и Заказчики. Пользователи регистрируются в системе, указывая свои контактные данные (имя, email, телефон) и получают статус (активен, заблокирован, на модерации).

Фрилансеры (исполнители) создают расширенный профиль, который включает: специализацию (дизайн, программирование, копирайтинг, фотография и т.д.), почасовую ставку, описание навыков, уровень образования и опыта. На основе отзывов заказчиков для фрилансера вычисляется профессиональный рейтинг. Ключевым элементом профиля фрилансера является портфолио - структурированное хранилище примеров работ. Портфолио организовано иерархически: фрилансер создает папки (альбомы) с названием и описанием, а внутрь папок загружает файлы (изображения, документы, видео, ссылки на внешние ресурсы). Каждый файл может иметь краткое описание. Файлы из портфолио могут быть привязаны к конкретным выполненным проектам.

Заказчики (клиенты) также имеют расширенный профиль, который может включать название компании (для юридических лиц), историю размещенных проектов и рейтинг как заказчика (формируется на основе честности и своевременности оплаты).

Взаимодействие между сторонами начинается с публикации Проекта (Заказа). Заказчик создает проект, указывая название, подробное описание задачи, требуемую специализацию, бюджет (фиксированный или почасовой), сроки выполнения. Проект получает статус "открыт" и становится доступным для откликов фрилансеров.

Фрилансеры направляют Предложения (Отклики) на открытые проекты. В отклике указываются предлагаемая цена (может отличаться от бюджета), сроки выполнения и сопроводительное письмо. Отклик может иметь статусы: "рассматривается", "принят", "отклонен", "отозван". На один проект может поступить множество откликов.

Если заказчик принимает предложение фрилансера, создается Контракт, который фиксирует начало работ. Контракт содержит согласованные условия (цена, сроки) и проходит через статусы: "активен" (в работе), "завершен", "оспорен", "отменен". В процессе выполнения работы стороны могут обмениваться файлами и комментариями (эта информация хранится в истории контракта).

После завершения работ заказчик производит оплату. Система фиксирует Платежи и Транзакции: поступление денег от заказчика, выплату фрилансеру (за вычетом комиссии платформы), статусы платежей (зарезервировано, выплачено, возвращено). По завершенному контракту обе стороны могут оставить Отзывы друг на друга с оценкой от 1 до 5, что влияет на их рейтинги.

Для структурирования всех видов деятельности ведется Справочник навыков и категорий, где перечислены все возможные специализации и конкретные навыки (например, Python, Photoshop, Копирайтинг на английском). Каждый фрилансер может привязать к себе несколько навыков, а каждый проект - несколько требуемых навыков.

Важнейшим компонентом системы является История заказов - полноценный лог всех действий и состояний, через которые прошел проект. Для заказчика история делится на: активные заказы (проекты в работе), открытые заказы (ожидающие откликов), завершенные заказы (успешно выполненные и оплаченные) и архив/отмененные. Для фрилансера история включает: текущие проекты, историю откликов (со статусами "рассматривается", "отклонен", "принят", "просрочен"), выполненные проекты и потерянные (отклики, не приведшие к контракту, или расторгнутые контракты). Каждая запись в истории содержит дату и время события, текущий статус, ссылки на связанные объекты (проект, контракт, платеж) и системные комментарии.

В личном кабинете каждого пользователя есть раздел "История заказов" / "Мои проекты" с возможностью фильтрации по датам, статусам, суммам и категориям. Для фрилансера завершенные проекты из истории могут быть в один клик добавлены в портфолио (автоматически создается папка и привязываются файлы). Для заказчика история позволяет быстро нанять проверенного фрилансера повторно.

Виды запросов в информационной системе

1. Поиск исполнителей. Получить перечень и общее число фрилансеров, обладающих указанным навыком (например, "Python"), либо имеющих рейтинг не ниже заданного, либо выполнивших не менее заданного числа успешных проектов (из истории заказов) за всё время или за указанный период. Дополнительная фильтрация: по полу, возрасту, стране проживания, размеру почасовой ставки.

2. Анализ клиентов. Получить перечень и общее число заказчиков, разместивших проекты в указанной категории (например, "Веб-дизайн") за некоторый период, либо потративших на проекты сумму не менее заданной (агрегация по истории завершенных заказов). Дополнительная фильтрация: по типу заказчика (частное лицо / компания), по рейтингу заказчика.

3. Просмотр портфолио. Получить структуру портфолио указанного фрилансера: перечень папок/альбомов и количество файлов в каждой. Получить список файлов в конкретной папке портфолио с возможностью фильтрации по типу файла (изображения, документы, видео) и дате загрузки.

4. Анализ рыночных цен. Получить сведения о средней стоимости и диапазоне цен на проекты в указанной категории по всем завершенным проектам (из истории), по проектам фрилансеров с определенным уровнем рейтинга, либо по проектам с фиксированным/почасовым бюджетом.

5. Продуктивность платформы. Получить данные о средней "выработке" (сумме закрытых контрактов) на одного активного фрилансера за указанный период по всем категориям, либо по категориям заданного типа, либо в разрезе специализаций фрилансеров.

6. Детальная история фрилансера. Получить полную историю заказов отдельно взятого фрилансера за указанный период с разбивкой по статусам (выполнено, в работе, отклики, проиграно). Дополнительно: фильтрация по заказчикам, по диапазонам сумм.

7. Популярность услуг. Получить данные об объеме продаж (количестве завершенных контрактов и их сумме) по указанной категории услуг за некоторый период по всем заказчикам, по заказчикам из определенной отрасли, по конкретному заказчику (из его истории покупок).

8. Финансы платформы. Получить данные о доходе платформы (комиссия с платежей) по всем проектам, по проектам заданной категории, по проектам конкретного фрилансера/заказчика (на основе истории платежей) за указанный период.

9. История сотрудничества. Получить сведения о проектах, выполненных определенным фрилансером для определенного заказчика (история взаимоотношений двух сторон) за все время, либо за некоторый период, с детализацией по суммам и отзывам.

13. Анализ "горячих" заказчиков. Получить сведения о заказчиках, которые разместили максимальное количество проектов за последний месяц (история новых заказов), имеют высокий рейтинг оплат и средний бюджет проекта выше заданного.

14. Топ исполнителей. Получить сведения о наиболее активных и высокооплачиваемых фрилансерах (Top Rated) по всем категориям, по категориям указанного типа, на основе истории их успешных проектов (суммарный заработок, количество проектов, средняя оценка).

15. История конкретного заказа. Получить полную хронологию событий по конкретному проекту: дата публикации, даты поступления откликов, дата принятия предложения и начала контракта, даты сдачи этапов (если фиксировались), дата финальной оплаты - в виде временной шкалы заказа.
