# FreelanSearch
SDP 2026

 Для запуска всего приложения:

   bash
     ./manage.sh start

   Этот скрипт автоматически:
   1. Создаст сеть elk_default (если она еще не создана).
   2. Запустит ELK-стек.
   3. Пересоберет и запустит все основные сервисы.

   Для полной остановки приложения:

   bash
     ./manage.sh stop

   Этот скрипт остановит и удалит контейнеры как основных сервисов, так и ELK-стека.
